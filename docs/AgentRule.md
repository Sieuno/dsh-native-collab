# Agent 仓库维护要求

1. **发布说明**：Release 只记录面向使用者的更新，不放入仓库和源码维护相关内容。
2. **临时资料**：过程资料、评估报告、参考文件及临时打包、测试产物放在仓库外。
3. **README 文档**：[中文 README](../README.md)和[英文 README](../README.en.md)只允许修改宿主支持版本；其他修改均需明确列出修改内容，并取得许可后才可进行。
4. **模块化提交**：以单一修改目的组织 commit，清楚说明修改内容与原因，便于审查、追溯和单独回退。同一目的涉及的源码、对应测试及必要文档可一并提交；不同目的的修改即使位于同一文件，也应拆分提交，不得混入同一个 commit。
5. **Markdown 文档维护**：除非确有必要，不应仅因开发过程需要或版本号更新而修改 Markdown 文档内容。CHANGELOG 除外，但应以发布为节点，根据最终更新结果维护，避免随开发过程反复改写或回退。
