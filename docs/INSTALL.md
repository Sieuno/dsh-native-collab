# 安装与升级指南

### 版本与环境要求
- **DeepSeek Harness**：`0.2.2-rc.2` 或 `0.2.2-rc.3`
- **Node.js**：`≥ 24.9.0`
- **旧版本兼容说明**：若您使用的 DSH 版本低于 `0.2.2-rc.2`，请继续使用 `0.3.5` 版本插件。

---

### 安装步骤

#### 1. 安装插件
- **通过官方源安装（待正式发布后）**：
  ```sh
  dsh plugin --profile <您的Profile名称> add @sieuno/dsh-native-collab
  ```
- **安装本地离线测试包（.tgz）**：
  ```sh
  dsh plugin --profile <您的Profile名称> add /path/to/sieuno-dsh-native-collab-0.4.0.tgz
  ```

#### 2. 重启 DSH
安装、启用或禁用插件后，请**完全退出并重启该 Profile 的 DSH 实例**。在浏览器中刷新网页不会重新加载插件后台服务。

停用时请关闭插件包的总开关，不要只关闭“包含的组件”中的「原生协作扩展」。DSH 停用整个包时会撤下本插件的配置补丁及其新增依赖；单独关闭内部组件不会撤下这些依赖。新版不再提供 `fallback` 占位组件。

#### 3. 配置与使用
重启后，进入「插件 → 已安装」，打开本插件的详情页，可设置「Subagent 模型来源」和「自动唤醒消息上限」。模型来源默认选择「官方默认策略」。修改后点击「保存」，即可立即对后续工具调用生效。
> [!NOTE]
> 子 Agent 的最大深度、并发数量、Team 模式及任务看板均直接使用官方原生入口，无需在扩展中重复配置。

---

## 从旧版本（0.3.5 及更早版本）升级

旧版插件通过替换官方协作服务实现功能，而新版全面重构为**基于官方核心的原生增量扩展**。为了保障平稳过渡，请参考以下升级建议：

1. **备份数据**：升级前请先备份您的 Profile 配置目录与重要会话数据。
2. **推荐在独立测试 Profile 中体验**：建议先在一个新的 Profile 中新建会话进行体验与验证。
3. **旧 Profile 升级步骤**：
   - 先在旧 Profile 中**停用旧版插件**，然后**完全重启 DSH**；
   - 验证官方原生子 Agent 与协作功能可正常使用；
   - 安装新版插件（或本地 .tgz 包），再次重启 DSH 即可。
4. **历史数据注意事项**：
   - 旧版本中通过“身份互转”写入的自定义团队历史数据无法自动迁移到官方原生树中，建议在升级后创建新会话开展协作；
   - 新架构已移除旧的独立导出（如 `/subagent`、`/agent-team`、`/tool-*` 等）；
   - 若升级或卸载后遇到 DSH 启动异常，通常是旧版配置覆盖未完全清除，请参考 [常见问题 (FAQ)](FAQ.md) 进行排查与清理。
