# 安装与使用指南

本项目仍是试用版本：尚未完成完整测试、真实 Profile 与真实 LLM 任务验证，兼容 DSH `>=0.2.1-rc.1 <0.2.2-0` 与 Node `>=22.19.0`，声明的支持范围不代表已验证。

## 1. 安装与启用

1. 在**你当前使用的 Profile** 下安装，无需先停止正在运行的实例（安装只向该 Profile 写入依赖）。把 `<profile>` 换成实际使用的 Profile 名（GUI 默认通常是 `web`）：

```sh
dsh plugin --profile <profile> add @sieuno/dsh-native-collab
```

若使用本地或离线包，把包名换成对应的 TGZ 包路径。

2. 关闭并重新启动该 Profile，然后进入插件管理页面。升级替换正在使用的旧版本时，建议先关闭该实例，避免 Windows 上的文件占用。

## 2. 设置配置与自动保存

- **自动保存**：页面中的所有修改均会自动保存，无需手动寻找保存按钮。若保存遇到问题，会在对应设置旁以红色文字提示具体原因。
- **无需手动改配置**：普通配置修改无需编辑配置文件，也不涉及服务切换。
- **生效机制**：
  - **模型来源**：保存后立即应用于后续的模型查询与子 Agent / Team 成员创建。
  - **启动配置**：增强开关及连续自动唤醒轮数上限等核心设置，在关闭服务后正常重启同一 Profile 即可生效（单纯刷新网页不算重启）。

## 3. 核心机制说明

- **单一管理入口**：插件 Patch 只插入一个管理入口，统一托管后台协作服务。管理入口开启时加载增强能力；若关闭入口并重启，系统将自动切回原生服务。
- **预设适配**：针对已知 AgentPreset 进行纯内存动态适配，不修改或固定原预设文件，亦不影响未知自定义 provider。官方实验包的四个根层工具仍保持禁用。
- **连续自动唤醒轮数上限**：
  - 默认上限为 32 轮，由 Team 家族共享，防止死循环。
  - 仅对无人类输入介入的连续跨会话自动唤醒进行计数。
  - 任一关联会话接收到人类输入即刻清零；计数仅保存在进程内存中，进程重启也会自动清零。
  - 子任务完成或停止结果向直属父级或 Team Lead 汇报不受此限。
- **任务进度查看**：请前往发起任务的对话中的 Team 面板或任务卡片查看，设置页面不展示实时任务流水。

## 4. 插件卸载

直接移除插件将自动清理 Patch 并恢复原生服务。常规使用无需手动编辑底层配置文件。若卸载、禁用或换版本后 DSH 无法启动（常见原因是 Profile 目录下的 `*.patch.json` 外部启动覆盖文件仍引用本插件），请按 [常见问题 (FAQ)](FAQ.md) 的启动修复步骤处理，切勿清空 patch 或删除会话数据。
