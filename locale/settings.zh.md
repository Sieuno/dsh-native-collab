# 原生协作扩展

本插件提供子 Agent 模型来源选择、共享自动消息额度与等待工具控制，并优化委派提示词。

### 配置与生效说明
修改下方选项后会自动保存，新设置对后续调用生效。消息上限仅在输入有效数字后保存。

### Subagent 模型来源

- **官方默认策略**（默认）：沿用当前会话的子模型授权。
- **当前子模型设置**：每次选模时读取 DSH 设置中的可用子模型列表。
- **所有已注册模型提供方**：可从当前已配置的所有模型提供方选择模型。

仅影响新建子 Agent；分叉会话沿用原有的模型继承规则。

### 自动唤醒消息上限

- 默认上限为 **32 次**，由整棵协作树内的所有 Agent 共同消耗，防止自主协作陷入死循环；
- 仅对成功接收的普通模型消息计数（发送失败自动退还额度，官方任务完成通知不计入）；
- 接收到用户输入消息或回复提问时，额度立即自动清零重置；进程重启后也会重新开始计数；
- 达到上限时仅拒绝该次消息发送，不会中断或取消 Agent；向直属父级提交完成结果的任务报告不占用额度。

### 禁用 Agent 等待工具 (wait_agent)

默认关闭。开启后，Agent 将无法调用 `wait_agent` 阻塞当前轮次等待子任务，促使其在派发任务后主动结束当前回复，静待子 Agent 完成时由官方完成通知自动唤醒继续执行（已在进行的等待会照常结束）。这能有效避免 Agent 陷入无效轮询，显著节省上下文 Token。

### 其它配置入口
子 Agent 的最大递归深度与并行数量上限请直接在官方原生「子智能体」设置中配置；会话级 Team 模式与任务看板请直接在对话界面中使用官方入口。
